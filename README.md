# people-said
People Said (PS): a personal quotes website with themes, sources and reflections.

https://people-said.vercel.app/

The link to People Said (PS) page on my Claude is
https://claude.ai/artifact/B6eEfAKsSPWdEv51ZAi8Qq

Open it while signed in to the Claude account you built it with to get the owner controls: add and edit quotes, themes, privacy, and Publish to visitors. Anyone else, or you while signed out, sees the view-only page.

people-said-editor-ver.html  
Preview of the functions accessible after signed in with owner controls.  
Storage: outside Claude, quotes are saved in your browser’s local storage. They stay on that browser and device. Clearing site data or switching browsers will lose them, so use “Download PDF” as a backup.  
Publishing: the “Publish to visitors” button isn’t in this version because there’s no hosting behind it. “Preview as viewer” still works.
